# صفحة بطاقة إعلانات تحت التدريب
مشروع تدريبي لتعلّم GitHub ووكلاء الذكاء الاصطناعي: صفحة بطاقة إعلان.

- تعلمت إنشاء فرع (Branch) لتجربة التعديلات بأمان.
- تعلمت كتابة رسالة Commit واضحة تبدأ بفعل إنجليزي.
- تعلمت كسر خطأ عمدًا واكتشافه من History.
- تعلمت قراءة Diff: الأحمر محذوف والأخضر مضاف.
- تعلمت إنشاء Pull Request ومراجعة Files changed.
- تعلمت الدمج في main وحذف الفرع بعده.
- تعلمت أن Revret وRestore branch يسمحان بالتراجع.
- تعلمت أن رقم # يخص Issue أو Pull Request.
- تعلمت أن Issue بطاقة مهمة وليست خطأ.
- تعلمت أن محرر GitHub يكمل القوائم تلقائيًا.
- تعلمت التأكد من الفرع قبل أي تعديل.
- تعلمت تحديث Pull Request مفتوح بحفظ جديد.
- تعلمت تعديل الملفات من تطبيق GitHub على الجوال.
- تعلمت إنشاء فرع أثناء الحفظ من الجوال.
- تعلمت فتح Pull Request من زر + في الجوال.
- تعلمت أن عنوان الطلب يصف الطلب كله لا آخر حفظ.
- تعلمت أن الصفحة الرئيسية في الجوال تعرض main افتراضيًا.
- تعلمت أن الرجوع للخلف لا يحذف الحفظ.
- تعلمت أن +6 -1 تعني غالبًا سطرًا معدلًا.
- تعلمت أن GitHub يظلل الكلمة المتغيرة داخل السطر.
- تعلمت أن انقطاع الشبكة لا يلغي الدمج الذي تم.
- تعلمت أن Files changed يعرض النتيجة النهائية فقط.
- تعلمت أن السطر الأخير الفارغ قد يكون نهاية الملف.
- تعلمت كتابة وصف لكل Pull Request.
- تعلمت اكتشاف أكثر من خطأ في مراجعة واحدة.
- تعلمت تصحيح عدة أخطاء في حفظ واحد.
- تعلمت أن المراجعة أهم خطوة قبل الدمج.
